# 실제 실습 원본

`start-class.cmd` 또는 `sh start-class.sh`가 준비된 수집기를 실행해 `case.json`을 저장합니다. 일반 게이트웨이를 통과한 실제 요청 2건을 Flask JSON 2행과 Nginx combined 텍스트 2행으로 읽습니다. 두 출처는 같은 요청의 서로 다른 관측이며 요청 4건을 뜻하지 않습니다.

수집 중에는 일반 게시판을 조작하지 않습니다. 실제 원본이 없거나 다른 기록이 섞이면 실패하고 이전 파일을 유지합니다. 이 파일을 수업 2~6에서 함께 사용하며 DB 기록은 삭제하지 않습니다. 생성된 로그 원본은 Git 제출 대상이 아닙니다.
